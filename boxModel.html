Box model

Cada elemento HTML se dibuja como una caja rectangular. Aunque uses border-radius para redondearla, solo cambia cómo se ve: sigue siendo una caja.

Esa caja tiene cuatro capas, de adentro hacia afuera: content, padding, border y margin. El dibujo de esta sección está hecho con esas mismas capas en CSS.

Excepciones: las listas y las tablas generan más de una caja, y los elementos con display: none o display: contents no generan ninguna.

Las cuatro áreas

De adentro hacia afuera.

1

Content

Lo que se ve: texto, imágenes, video… Su tamaño se controla con width, height, min-* y max-*.

2

Padding

El espacio entre el contenido y el borde. Es transparente, pero el fondo de la caja se extiende por él. No acepta valores negativos.

3

Border

La línea que rodea la caja. Se define con border-style, border-width y border-color.

4

Margin

La separación con las otras cajas. Es transparente, no muestra el fondo y sí puede ser negativo.

Ojo con el tamaño: width y height solo miden el content. El padding y el border se suman encima para dar el tamaño total de la caja.

Bloque o en línea

Depende de la propiedad display.

Caja de bloque

Ocupa todo el ancho de su contenedor. Ejemplo: <div>.

Caja en línea

Atajos de padding y margin

Los valores van como las agujas del reloj, empezando a las 12: arriba, derecha, abajo, izquierda.

top right bottom left ↻
padding: 10px;

Los cuatro lados iguales.

padding: 10px 20px;

10px arriba y abajo, 20px a los lados.

padding: 10px 20px 30px;

10px arriba, 20px a los lados y 30px abajo.

padding: 10px 20px 25px 5px;

Arriba 10px, derecha 20px, abajo 25px, izquierda 5px.

Lo mismo funciona con margin. Los recuadros rosados de arriba usan ese mismo padding de verdad.

¿Margin o padding?

Las dos dan espacio, pero no sirven para lo mismo.

Usa padding cuando…

  • El contenido no debe tocar el borde.
  • El fondo tiene que cubrir el espacio extra.
  • Quieres agrandar un elemento, como un botón.
  • Quieres separar un hijo de su contenedor.

Usa margin cuando…

  • Quieres separar elementos hermanos.
  • Quieres centrar horizontalmente.
  • Quieres mover un elemento.
  • Quieres superponer elementos.

Para tener en cuenta

Detalles que ayudan a entender y depurar las cajas.

Outline

Se dibuja entre el border y el margin, pero no ocupa espacio ni es parte del box model. Se usa para accesibilidad con :focus y :focus-within.

Colapso de márgenes

Cuando dos elementos vecinos tienen márgenes que se tocan, esos márgenes se fusionan en un solo espacio.

Ver todas las cajas

Este truco dibuja el contorno de todos los elementos de la página:

* { outline: 1px solid red; }
