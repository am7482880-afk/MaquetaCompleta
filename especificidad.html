Especificidad CSS

Es la forma en que el navegador resuelve los conflictos cuando varias reglas le dan estilo a un mismo elemento: así decide qué estilos son más importantes y cuáles se aplican.

Para decidir, le da a cada selector un puntaje de cinco columnas. Cada parte del selector suma 1 en su columna y los puntajes se comparan de izquierda a derecha.

#menu .item a
!important0
en línea0
#id1
.clase1
elemento1

1 id + 1 clase + 1 elemento = 0,0,1,1,1

De menos a más peso

Cada escalón le gana a todos los que están por debajo.

* 0,0,0,0,0

Universal: no tiene peso, cualquier regla lo reescribe.

p 0,0,0,0,1

Elementos: los estilos más básicos y fáciles de reescribir.

.clase 0,0,0,1,0

Clases, atributos y pseudoclases: la mejor opción para dar estilos.

#id 0,0,1,0,0

ID: pesa más que clases y etiquetas; mejor para funcionalidad.

style="" 0,1,0,0,0

En línea: se aplica aunque el elemento tenga clases o id.

!important 1,0,0,0,0

Pasa por encima de todo. Úsalo con mucho cuidado.

¿Quién gana?

Dos reglas le dan estilo al mismo elemento. Gana la de mayor puntaje.

.boton 0,0,0,1,0
vs
button 0,0,0,0,1

Gana la clase, aunque button esté escrito de último: es más específica.

nav .menu a 0,0,0,1,2
vs
#menu a 0,0,1,0,1

Gana el id: se compara de izquierda a derecha y la columna del id va antes que la de clases.

p { color: red; } 0,0,0,0,1
vs
p { color: blue; }
(escrito después) 0,0,0,0,1

Empate: cuando dos reglas pesan lo mismo, gana la última que se escribió.

#titulo 0,0,1,0,0
vs
style="color: pink" 0,1,0,0,0

Ganan los estilos en línea: pesan más que cualquier id.

style="color: pink" 0,1,0,0,0
vs
color: brown !important 1,0,0,0,0

Gana !important: reescribe cualquier estilo, incluso los de línea.

* 0,0,0,0,0
vs
div 0,0,0,0,1

Gana el elemento: el selector universal no tiene peso.

Así decide el navegador

La cascada, paso a paso.

  1. Lee de arriba hacia abajo

    Recorre el CSS y va clasificando las reglas según su importancia.

  2. Ignora lo que no entiende

    Un error no detiene el CSS: si un valor no es válido, lo salta y sigue.

  3. Calcula el puntaje

    Si varias reglas chocan con distinta importancia, gana la de mayor puntaje.

  4. Desempata por orden

    Si pesan lo mismo, se queda con la última que se escribió.

Consejos

Para que la especificidad no se vuelva un problema.

Busca el equilibrio: lo bastante específico para que se aplique y lo bastante general para poder reescribirlo.

Prefiere las clases para dar estilos, y deja los id para funcionalidad.

Evita selectores muy largos: cuestan leerlos y mantenerlos.

Usa una metodología como BEM para mantener el orden.

Comenta y organiza tu CSS con el mismo cuidado que el HTML y el JS.
