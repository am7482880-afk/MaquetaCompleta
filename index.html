Estructura y sintaxis Niveles de especificidad Pseudoclases y elementos Box model
01

¿Qué es un documento CSS?

Es un archivo de texto, igual que un HTML, pero con extensión .css. Dentro van las órdenes de estilo que el navegador lee y aplica a la página.

02

Enlazar CSS con HTML

Lo recomendable es usar la etiqueta <link> dentro del <head>. En href va el nombre del archivo: 

<link rel="stylesheet"
      href="css/estilos.css">
03

Estructura de un bloque

Primero va el selector y luego, entre llaves, las reglas con su propiedad y su valor:

p {
  color: red;   /* color de texto */
}

Este bloque pinta de rojo todos los <p> de la página.

04

Conceptos clave

  • Selector: los elementos a los que se les da estilo.
  • Propiedad: la característica que se cambia, como el color.
  • Valor: el dato que se le da a la propiedad.
  • Regla: la pareja propiedad + valor.
05

Comentarios

Se escriben entre /* y */. Son notas para las personas: el navegador las ignora.

/* Menú */
06

Buenas prácticas

  • Una regla por línea: el código se lee y se modifica más fácil.
  • Indentación: después de abrir la llave {, las propiedades se corren hacia la derecha.
  • Punto y coma al final: cada regla termina en ;. En la última del bloque es opcional, pero conviene ponerlo siempre.

No son obligatorias para que funcione, pero a medida que el CSS crece ayudan a mantenerlo ordenado.

07

Errores comunes

  • Olvidar el <link> en el HTML: los estilos no se aplican.
  • No separar las reglas con ;.
  • Escribir mal el selector o la propiedad.
  • Abrir un comentario con /* y no cerrarlo con */.
08

En resumen

Un archivo CSS está formado por muchos bloques: cada uno tiene un selector y, entre llaves, varias reglas propiedad: valor;.
