Pseudoclases CSS

Las pseudoclases permiten seleccionar elementos HTML según su comportamiento o el estado en el que se encuentran en el navegador, y no solo por su etiqueta, clase o id. La más conocida es :hover, que cambia el estilo de un elemento cuando pasamos el ratón por encima.

Se agrupan en siete tipos: de interacción, de ubicación, de idioma, de estructura, de formulario, de estado y de paginado.

Sintaxis

Se escriben poniendo dos puntos : después del selector y luego el nombre de la pseudoclase.

a {
  color: #604734;
}

a:hover {
  color: #F0C5D4;
}
Interacción

:hover

Se activa cuando el usuario pasa el ratón (u otro puntero) por encima del elemento.

Interacción

:active

Se aplica mientras el elemento está siendo pulsado o clicado.

Interacción

:focus

Se aplica cuando el elemento tiene el foco, por ejemplo un campo de texto seleccionado.

Interacción

:focus-within

Se aplica a un contenedor cuando alguno de los elementos que tiene dentro recibe el foco.

Interacción

:focus-visible

Se aplica al elemento con foco solo cuando el navegador considera que el foco debe verse, como al navegar con el teclado.

Ubicación

:link

Selecciona los enlaces que el usuario todavía no ha visitado.

Ubicación

:visited

Selecciona los enlaces que el usuario ya ha visitado.

Ubicación

:target

Selecciona el elemento cuyo id coincide con el ancla de la URL, por ejemplo #contacto.

Idioma

:lang()

Selecciona elementos según el idioma en que están escritos, por ejemplo :lang(es).

Idioma

:dir()

Selecciona elementos según la dirección del texto: de izquierda a derecha (ltr) o de derecha a izquierda (rtl).

Estructura

:root

Selecciona el elemento raíz del documento, que en HTML es la etiqueta <html>.

Estructura

:first-child

Selecciona el elemento que es el primer hijo dentro de su padre.

Estructura

:last-child

Selecciona el elemento que es el último hijo dentro de su padre.

Estructura

:only-child

Selecciona el elemento que es el único hijo de su padre.

Estructura

:nth-child()

Selecciona hijos según su posición: :nth-child(2), :nth-child(odd), :nth-child(even)…

Estructura

:first-of-type

Selecciona el primer elemento de su tipo dentro del padre, por ejemplo el primer <p>.

Estructura

:empty

Selecciona los elementos que no tienen ningún contenido dentro.

Formulario

:checked

Selecciona las casillas o botones de opción que están marcados.

Formulario

:disabled

Selecciona los campos de formulario que están desactivados.

Formulario

:required

Selecciona los campos que son obligatorios porque tienen el atributo required.

Formulario

:placeholder-shown

Selecciona los campos que están mostrando su texto de ejemplo (placeholder) porque siguen vacíos.

Formulario

:valid

Selecciona los campos cuyo valor cumple la validación.

Formulario

:invalid

Selecciona los campos cuyo valor no cumple la validación, como un correo mal escrito.

Estado

:fullscreen

Selecciona el elemento que se está mostrando a pantalla completa.

Paginado

:first

Selecciona la primera página de un documento al imprimirlo; se usa junto con @page.
